# Сравнение GitHub и ZIP

**GitHub:**
- Плюс: удобно, видна история изменений.
- Минус: можно случайно выложить личные данные.
- Воспроизводимость: высокая.

**ZIP-архив:**
- Плюс: безопасно, файл лежит только у тебя.
- Минус: нет истории версий, нужно распаковывать.
- Воспроизводимость: средняя.

**Вывод:**
Для учёбы лучше ZIP (безопаснее). Для портфолио лучше GitHub (удобнее).
